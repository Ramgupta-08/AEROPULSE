# Chapter 34 — Avionics and Navigation

## GMM 34-10 Intermittent display blanking
Run BITE, reseat and clean connectors, check for moisture. Replace display if fault persists after connector rectification.

## GMM 34-20 Moisture ingress in avionics bay
Common at humid bases during monsoon. Dry the bay with warm air, replace desiccant, fit sealed connector kit to affected plugs and
check door seals. Inspect for corrosion on connector pins.

## GMM 34-30 INS drift beyond limit
Re-align on a surveyed point, reload software. Replace inertial navigation unit if drift persists.
