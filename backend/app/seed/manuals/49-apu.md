# Chapter 49 — Auxiliary Power Unit

## GMM 49-10 APU fails to start or hung start
Symptoms: no light-off, slow acceleration, start aborted on time-out, worse after overnight cold soak.
Likely causes:
1. Igniter exciter or plug degraded — weak spark in cold, thin air.
2. Starter-generator brush wear — low cranking speed.
3. Fuel control scheduling too lean for cold conditions.
4. Battery voltage low at low ambient temperature.
Recommended checks:
- Check battery voltage under load (minimum 22 V) and pre-heat battery in extreme cold.
- Perform igniter audible spark check; replace igniter exciter if intermittent.
- Measure cranking speed; below 18 % at light-off window indicates starter-generator wear.
- Review cold-start fuel schedule adjustment for high-altitude bases.
High-altitude bases: use ground pre-heat below −10 °C and the cold-start procedure; record OAT on every start fault so trends can be tracked.

## GMM 49-20 APU over-temperature on load
Check inlet for blockage, verify bleed demand, replace temperature sensor if EGT indication is erratic.
